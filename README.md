# Kaan Topcu Portfolio

A bilingual, production-focused portfolio website for Kaan Topcu, a backend developer focused on APIs, databases, integrations, and scalable service architecture.

## Overview

This portfolio is designed as a calm, technical, and responsive single-page experience with English and Turkish language support. It presents selected backend projects, professional experience, technical stack, additional GitHub work, contact links, a themed loading screen, and a custom 404 page.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- React Router DOM
- lucide-react

## Features

- Bilingual EN/TR content system
- Responsive layout for mobile, tablet, and desktop
- Smooth scroll-based homepage
- Selected backend project case cards
- Experience timeline
- Technical stack section with categorized tools
- Additional public GitHub repositories
- Branded first-load loading screen
- Custom image-free 404 page
- Optimized logo asset and SEO basics

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Notes

The site does not require environment variables. Public assets include the portfolio logo, CV PDF, and `robots.txt`.
